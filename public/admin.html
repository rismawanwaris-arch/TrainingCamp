Download Backup Database

Unduh salinan file database SQLite (.db) ke komputer Anda.

File backup berisi seluruh data penting website:

  • Seluruh tutorial & panduan yang telah dibuat
  • Struktur kategori modul & status kunci akses
  • Daftar akun pengguna dan role admin
  • Seluruh link video Google Drive & YouTube

Sistem otomatis menjalankan SQLite WAL flush sebelum pengunduhan untuk menjamin integritas data 100%.

Restore Database

Pulihkan data tutorial dari file backup (.db) yang sudah disimpan sebelumnya.

Perhatian Sebelum Restore:

Proses ini akan menimpa database aktif saat ini dengan data dari file backup. Pastikan Anda mengunggah file backup yang benar.

Pilih file backup (contoh: tutorials-backup-2026-10-06.db).

Jaminan Keamanan Data saat Update Aplikasi

Semua data tersimpan secara permanen di storage server ZimaOS Anda pada path ./data/tutorials.db (Docker Persistent Volume) dan BUKAN di RAM atau di dalam image container sementara.

Setiap kali Anda menjalankan git pull atau docker compose up -d --build untuk update kode/fitur website, database ini tidak akan pernah terhapus atau tertimpa. Fitur backup di atas berguna sebagai pengaman ekstra jika Anda ingin menyimpan arsip di luar server.
